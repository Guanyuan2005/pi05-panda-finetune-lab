# Receding action 执行对比

正式 checkpoint：`panda_formal_v1/19999`；测试场景：seed=50000。

| 每次观测后执行动作数 | 成功率 | 平均推理耗时 |
|---:|---:|---:|
| 1 | 0/1 | 189.97 ms（首轮编译） |
| 3 | 0/1 | 84.50 ms |
| 5 | 0/1 | 84.93 ms |

随后使用训练 episode 0 的完全同场景（scene_seed=10000、相同 positions/tray）执行 1 步滚动，仍为 0/1。

结论：改变 action 保持长度不能修复当前失败；失败也不是仅由 held-out 场景泛化造成。基础控制器、场景、首帧观测和动作单位已通过独立回放验证，当前主要问题收敛到策略没有学到可闭环执行的长时序动作，或训练时动作序列窗口与推理执行语义不一致。下一步应审计 LeRobot/OpenPI 训练样本的 action 序列窗口（`action[t:t+H]` 是否实际对应观测 `observation[t]`），再考虑重新训练，而不是继续只调执行步数。
